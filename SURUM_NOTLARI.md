# Ticaret İmparatorluğu V53

V53 Android APK içindeki `assets/www/` web kaynaklarından çıkarılmıştır.

- `index.html`: V53 oyun sürümü
- `sw.js`: PWA servis çalışanı
- `manifest.webmanifest`: uygulama tanıtımı (orijinal APK içindeki ad "Mobil V51" olarak kalmış)
- `assets/`: üç uygulama simgesi

V52 ile karşılaştırmada V53 HTML içine Android güncelleme düğmesi ve Android yedek kaydetme uyumluluğu eklendiği tespit edildi.

**Not:** Bu paket Android APK ya da Android Studio projesi değildir; APK içindeki düzenlenebilir web kaynaklarıdır.
